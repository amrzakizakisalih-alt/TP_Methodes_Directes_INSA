# TP Direct Methods — INSA Rouen Normandie

This repository contains the work completed for **TP 1 – Direct Methods** at **INSA Rouen Normandie**.

The project focuses on the numerical resolution of linear systems using direct numerical methods.

## Contents

The TP focuses on numerical methods for solving linear systems of the form:

$Ax = b$

The implementations and associated results can be found in the **Codes finaux directory**.

The report presents the methods studied, the implementation process, and the numerical results obtained.

## Compilation & Execution

### Requirements

*The project requires Python 3 and the following scientific computing libraries*:

    pip install numpy scipy matplotlib
---
## Running the Programs

Navigate to the directory containing the Python source files and run a program using:

    python3 program.py
